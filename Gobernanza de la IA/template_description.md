# Template: Gobernanza de la IA — Cruces Decorativas

## Estilo visual
**Cruces Decorativas** — cuatro marcas en cruz (+) posicionadas en las esquinas de cada slide. Las cruces son el único elemento gráfico decorativo; no hay marcos completos, texturas ni formas adicionales. El estilo transmite precisión institucional, rigor analítico y estructura — sin ser frío.

## Paleta
| Rol | HEX |
|---|---|
| Fondo portada | `#f0e8ff` (lavanda clara) |
| Fondo slides de contenido | `#f0e8ff` (lavanda clara) |
| Fondo slides alternados | `#e4d4ff` (lavanda profunda) |
| Fondo slide de cita | `#e4d4ff` (lavanda profunda) |
| Fondo slide de cierre | `#9b5de5` (violeta acento) |
| Cruces y acentos | `#9b5de5` |
| Texto principal | `#1a1a1a` |

## Tipografía
**Outfit** — familia única, variación por peso.
- Datos / números destacados: `900`
- Títulos de sección: `700`
- Citas: `600 italic`
- Cuerpo: `400`
- Labels / tags: `300`, `letter-spacing: .15em`, `uppercase`

## Estructura de los slides

### Portada
- Fondo: lavanda clara (`#f0e8ff`)
- Cruces: violeta acento — `opacity: .4`
- Contenido: label del pilar + título + bajada/pregunta + @unpibedecompu

### El Problema
- Fondo: lavanda profunda (`#e4d4ff`)
- Cruces: violeta acento — `opacity: .25`
- Contenido: label + título + separador + cuerpo

### Qué Propone

## Reglas de composición
- Tamaño de slide: `1080×1080 px` (Instagram nativo)
- Padding exterior (borde al contenido): `86px` en todos los lados
- Cruces: SVG `80×80 px`, posicionadas a `54px` de cada esquina, `opacity: .25-.4`
- Separador entre secciones: línea de `130px × 8px` en acento
- Labels de sección: `2.6rem`, `letter-spacing: .15em`, `uppercase`, `font-weight: 300`
